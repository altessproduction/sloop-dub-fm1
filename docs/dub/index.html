01 — performance

Le rythme, la basse et l’accord au même endroit.

Les patterns utilisent des pas de 16, 32 ou 64 cases. Les accents sont inspirés du jeu one-drop / steppers et peuvent être modifiés pas par pas.

03 — fondations

Construit sur SLOOP, pensé pour le dub.

Cette livraison ne change pas le format des projets SLOOP. Le firmware et la surface web évoluent de manière contrôlée afin de préserver les sessions existantes.
